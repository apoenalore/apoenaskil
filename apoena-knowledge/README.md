# Conhecimento do Universo Apoena

Este diretório reúne uma primeira transferência documentada do conhecimento de Apoena para consulta por outras IAs. Não substitui os documentos-fonte nem pretende declarar recuperado todo o histórico do projeto.

## Como consultar
1. Leia `../README.md` (se existir) e este índice.
2. Leia `canon-status.md` antes de tratar qualquer informação como definitiva.
3. Consulte a Skill temática adequada.
4. Respeite os rótulos de proveniência: **CÂNONE DOCUMENTADO**, **DECISÃO DO AUTOR EM CONVERSA**, **PROPOSTA DA IA**, **PENDENTE** ou **LACUNA**.
5. Em conflito, prevalece a correção explícita mais recente do criador. Preserve versões anteriores no histórico; não as apague.

## Limites desta transferência
O acesso disponível inclui conversas recentes do projeto e três PDFs anexados nesta sessão. Não equivale ao acesso integral a todas as conversas históricas, anexos antigos, imagens originais ou branches do repositório. O arquivo `Livro.pdf` tem duas páginas sem texto extraível; não foi possível identificar seu conteúdo. Os PDFs foram lidos como fontes, mas os binários originais ainda não foram copiados para este repositório.
