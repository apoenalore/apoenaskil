# Registro de decisões autorais

Registre decisões explícitas do autor que alterem ou esclareçam o cânone.

Modelo:

```md
## DEC-0001 — Título
- Data:
- Status: aprovado
- Tema:
- Decisão:
- Fonte/contexto:
- Documentos afetados:
- Observações:
```

Uma decisão mais recente só substitui uma anterior quando isso estiver explícito.
