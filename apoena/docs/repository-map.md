# Mapa dos repositórios Apoena

**Atualizado:** 2026-10-30  
**Status:** inventário técnico baseado nos READMEs e documentos consultados. Não é declaração de que todos os recursos estejam concluídos.

## Regra de separação

Os repositórios abaixo têm responsabilidades distintas. Não copiar arquivos, regras, saves, validações ou decisões entre eles sem uma tarefa explícita e uma verificação de compatibilidade. Protótipos e ferramentas não alteram automaticamente o cânone do mangá.

| Repositório | Responsabilidade recuperada | Relação com Apoena |
|---|---|---|
| `apoenaskil` | Biblioteca central de Skills e conhecimento | Documentação/transferência para IAs |
| `projeto-apoena-studio-maker-ia` | Studio Maker: fichas, referências, geração/edição visual e editor de mangá | Produção visual e organização de materiais |
| `JOGO-APOENA-AGAR-` | Jogo Godot 4: arena/MOBA 3D e Modo História alfa | Adaptação jogável, não fonte automática do cânone |
| `Apoena-pixel-art-html` | Jogo Pixel Art com modo MOBA e exploração/Floresta Viva; protótipos HTML e Godot | Projeto de jogo separado do MOBA 3D |
| `GameCreator` | Ferramenta de autoria de sprites, mapas, tilesets, assets, catálogos e dados | Exporta recursos/contratos para jogos consumidores |
| `que-projeto-e-esse` | Lore Engine, editor 3D independente para recursos e personagens | Ferramenta experimental; exportações só quando autorizadas |
| `APOENA-AI-HUB-IA` | Aplicação de IA em construção | Não confundir com a biblioteca de Skills |

## Limites de acesso nesta recuperação

Foram lidos arquivos textuais. Imagens binárias, modelos GLB/FBX, PDFs e anexos distribuídos fora do GitHub não foram baixados nem preservados nesta etapa. Alguns READMEs apontam arquivos originais em branches de arquivo ou ZIPs de conversa; seus conteúdos não foram copiados para esta biblioteca.

## Cuidados de nomenclatura

O README do jogo 3D usa a grafia **Ubirara** em algumas seções e **Ubirará** em outra, enquanto a documentação de cânone consultada usa **Birará**. Não assumir que Ubirara/Ubirará e Birará são a mesma pessoa, nem normalizar os nomes sem decisão do autor. O jogo também usa nomes de protótipo como Aqua, CH44 e Oriom; confirmar cada identidade com as fichas canônicas antes de consolidar.
