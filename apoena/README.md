# Universo Apoena — biblioteca de skills

Esta pasta reúne as instruções e referências de IA exclusivas do projeto Apoena dentro da biblioteca geral `apoenaskil`.

Comece por:
1. `AGENTS.md` — regras obrigatórias.
2. `docs/canon-status.md` — estado e lacunas do material.
3. `docs/aurium-system.md` e `docs/cosmology.md` — resumos de referência.
4. `skills/INDEX.txt` — índice das habilidades.

**Importante:** esta versão é uma base inicial. Não representa análise integral de todos os PDFs nem contém a história, personagens e geografia completos. Não invente o que ainda não foi catalogado. Marque lacunas e peça validação do autor.
