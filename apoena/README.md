# Universo Apoena — biblioteca de skills

Esta pasta reúne as instruções e referências de IA exclusivas do projeto Apoena dentro da biblioteca geral `apoenaskil`.

## Comece por aqui
1. `AGENTS.md` — regras obrigatórias para agentes.
2. `docs/knowledge-recovery-2026-10-30.md` — inventário do que foi recuperado, fontes consultadas e lacunas.
3. `docs/canon-status.md` — estado e lacunas do cânone.
4. `docs/aurium-system.md`, `docs/constellations-system.md` e `docs/cosmology.md` — referências de lore/poder.
5. `docs/game-design-notes.md`, `docs/game-design-recovered.md` e `docs/ecology-game-notes.md` — sistemas de jogo, separando implementação, plano e proposta.
6. `docs/repository-map.md` — mapa dos repositórios e responsabilidades.
7. `skills/INDEX.txt` — índice das habilidades.

## Como usar
- Para lore, narrativa e personagens, escolha a Skill correspondente e consulte as fontes de cânone.
- Para Aurium, use `apoena-aurium-system`; para constelações, `apoena-constellations-and-blessings`.
- Para mecânicas, coop ou prototipagem, use `apoena-game-systems` e/ou `apoena-godot-prototyping`.
- Para profissões/economia, use `apoena-progression-economy`.
- Para natureza da Floresta Viva, use `apoena-ecology-systems`.
- Para arquitetura dos produtos e limites entre repositórios, use `apoena-project-architect`.
- Para recuperar novos materiais, use `apoena-knowledge-archivist`.

**Importante:** a transferência ainda é parcial. Não representa análise integral de todos os PDFs ou conversas antigas. Não invente o que ainda não foi catalogado. Marque lacunas e peça validação do autor.
