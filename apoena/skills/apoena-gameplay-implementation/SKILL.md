# Apoena Gameplay Implementation
Leia docs/game-design-recovered.md, docs/gameplay-parameters-recovered.md e docs/ecology-game-notes.md.
1. Identifique o produto/repositório antes de editar.
2. Classifique o pedido: decisão, protótipo, proposta ou experimento.
3. Consulte código, cenas, branch e commit antes de afirmar implementação.
4. Não misture jogo com Studio Maker, Lore Engine, AI Hub ou Browser.
5. Preservar Aurium (AUR) como recurso; não renomear para mana.
6. Não transformar balanceamento em cânone narrativo.
7. Registrar teste real em dispositivo quando o alvo for Android.
8. Não inventar regra para números incompletos; pedir decisão.
