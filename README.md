# Apoena Skills

Biblioteca de instruções especializadas para orientar agentes de IA no universo, cânone e produção narrativa/visual do mangá **Apoena**.

## Estrutura
- `AGENTS.md`: regras gerais obrigatórias para agentes.
- `skills/`: habilidades especializadas.
- `docs/`: referências resumidas de cosmologia, Aurium, cânone e produção visual.
- `canon/`: materiais aprovados pelo autor.
- `decisions/`: decisões autorais e histórico de alterações.

## Skills
- `apoena-canon-guardian`: protege o cânone.
- `apoena-worldbuilding`: desenvolve mundo e cosmologia.
- `apoena-scriptwriter`: roteiro, cenas e diálogos.
- `apoena-art-director`: direção visual e composição.
- `apoena-character-designer`: fichas e consistência de personagens.
- `apoena-image-production`: imagens, edição e spritesheets.
- `apoena-continuity-reviewer`: continuidade e contradições.

## Estado do material
Esta é uma base inicial, não a enciclopédia completa. Os resumos em `docs/` foram montados a partir dos materiais localizados até agora. Os PDFs originais, fichas completas, cronologia, geografia, facções, arcos e bíblia visual ainda precisam de catalogação e validação integral.

**Regra principal:** a IA auxilia o autor; não decide o cânone. Toda lacuna deve ser marcada como desconhecida ou proposta, nunca preenchida silenciosamente.
