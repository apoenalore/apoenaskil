## Estrutura
- apoena/AGENTS.md: regras gerais obrigatórias para agentes.
- apoena/docs/MODOS_DE_TRABALHO_E_PRESERVACAO.md: modos de trabalho e protocolo de recuperação integral.
- apoena/skills/: Skills especializadas, cada uma com SKILL.md.
- apoena/docs/: conhecimento recuperado, proveniência, modos de trabalho, registros de conversas e lacunas.
- apoena/references/: inventário de fontes e transcrições com marcadores de página.
- apoena/canon/: materiais aprovados.
- apoena/decisions/: decisões registradas.

## Regras
A IA auxilia o criador; não decide o cânone. Não inventar para preencher lacunas. **Não perder conhecimento para ganhar organização:** preservar versões antigas, atuais, descartadas, incompletas e divergentes. O modo padrão para importar material de outras IAs, conversas antigas, documentos ou repositórios é Recuperação Integral. Primeiro preservar; depois organizar; em seguida comparar; por último atualizar com o autor. Separar cânone confirmado, decisão do autor, recuperação a validar, implementação verificada/histórica, planejamento, proposta, descartado e desconhecido. Correções explícitas recentes definem o estado atual no mesmo escopo, mas não apagam o histórico. Não confundir mangá com protótipos do jogo nem misturar repositórios.

## Limite
Os PDFs originais permanecem na Biblioteca; o GitHub recebeu extrações textuais, não cópias binárias. As transcrições não preservam imagens/diagramação e podem conter erros de OCR. A página 90 da cosmologia requer conferência visual. Fichas completas, mapas, cronologia total, bíblia visual e outros anexos ainda estão incompletos.
